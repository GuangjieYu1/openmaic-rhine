# Rhine / OpenMAIC native integration

## Entrypoints

- `/reinlab`: course archive using the native course store. Decorations are not courses. Zero-scene shells are omitted; up to 32 real courses per physical archive page.
- `/`: original course-creation home with Rhine colors, the animated Curriculum Studio mark, and a return-to-archive link. The archive's “课程创作” entry first stages this mark centrally, then carries it into the home-page lockup without a second-logo flash.
- `/workspace`: real Pro workspace if configured; otherwise an explicit prerequisite notice. No mock chat.
- `/reinlab?course=<encoded id>&from=reinlab`: native ClassroomSurface hosted in the archive's persistent transition shell.

The legacy ReinLab app on port 5173 now sends learning entries through a document-shutter transition to port 3000. The native archive has an equally explicit animated return to `http://127.0.0.1:5173/?return=archive`, which resumes the physical learning lane rather than replaying login. The nested classroom arrow returns to the native archive, not the course-creation home; the archive then returns to ReinLab. Research remains independent. OpenMAIC's source origin stays port 3000 so browser-owned courses retain their original storage origin.

## Theme

`app/rhine-theme.css` provides light/dark semantic tokens and Rhine palette ramps for home, generation, workspace and native classroom chrome. The default logo, new blank slides, generated slide backgrounds and theme colors use Rhine assets/paper/sage. Imported and previously authored slide objects, images, video and interactive iframe documents are not forcibly recolored. New visitors default to light mode; stored preferences are honored.

## Data and resume

The archive uses `listStages` and native device current-scene storage. If the Pro runtime is enabled, it also reads the owner-scoped server index, deduplicating course ids. The Pro workspace's course tree now merges the same server index with browser-owned courses, marks their source, and does not list empty Agent draft shells as completed classrooms. The classic guided-generation homepage intentionally keeps its existing local library until its standalone classroom route can support owner-scoped Agent documents; it does not show server courses that its own route cannot open. This does not switch NEXT_PUBLIC_PERSISTENCE or migrate/delete existing browser courses. Owner-scoped server courses use `/api/stages/[id]` instead of the old public-share endpoint and open read-only to prevent overwriting the agent's document with a browser-local copy. The workspace's right pane now uses this same owner-scoped load and renders Agent courses as read-only lesson previews rather than waiting on an editor it cannot open. Their scene bookmark stays device-scoped and writable. Local courses keep the original native loader.

Action-resume positions are mirrored to durable browser storage with fallback to previous session-only records. Existing action-id/type and safe-prefix validation is retained. Storage refusal remains best-effort. No fabricated mastery/progress data is added.

## Opening safety

ClassroomSurface reports loading/stage/error/not-found. The transition waits for the real stage and has cancellation/timeout handling. `allowBackgroundGeneration=false` prevents automatic generation/narration adoption when opening an existing course from the archive. The native course editor remains available at the original routes. This archive entry intentionally does not auto-repair missing media through paid calls.

## Local runtime

Docker's engine remained unresponsive, so a separate native PostgreSQL 16 cluster was initialized in `~/Library/Application Support/ReinLab/OpenMAIC/pg16-data`, bound to `127.0.0.1:55433`. The original Homebrew default cluster, existing Docker containers and databases were not started or modified. Its credentials exist only in the git-ignored, mode-600 `.env.local`. Backups `.env.local.before-rhine`, `.env.local.before-runtime`, and `.env.local.before-deepseek` are local. `NEXT_PUBLIC_PERSISTENCE` remains off to preserve browser-owned course listing and writes; agent-owned courses are separately read by the archive.

The Pro runner's first local Ollama `qwen3.5:9b` attempt ran for minutes and failed at the model output limit before any tool call. The server-only driver route and default model now use the configured DeepSeek provider (`deepseek-v4-flash`). The user placed `DEEPSEEK_API_KEY` locally in `.env.local`; its value is not copied into source or this document. The workbench entry is fail-closed when a server-side driver key is absent. After the service was restarted with the configured file, `/api/agent/runtime` reported `driverReady: true` and the real `/workspace` opened.

This deployment currently has no server TTS capability or bindable voices. Agent-generated speech scripts are readable, but audio synthesis does not work until TTS is separately configured. This limitation is independent of the DeepSeek text/agent connection.

This local database was started manually, not registered as an auto-start service. After a machine reboot, start it with `/opt/homebrew/opt/postgresql@16/bin/pg_ctl -D "$HOME/Library/Application Support/ReinLab/OpenMAIC/pg16-data" -l "$HOME/Library/Application Support/ReinLab/OpenMAIC/postgres.log" -o "-h 127.0.0.1 -p 55433 -k /tmp" start` before starting OpenMAIC.

## Build / rollback

Changes live on branch `codex/rhine-openmaic`. `RHINE_BUILD_DIR=.next-rhine-v8 pnpm build` makes a side-by-side production build; the original `.next/standalone` release and the v6/v7 Rhine builds remain available. Older regenerable v2–v5 build output was removed when local disk space ran low; no course data or browser storage was cleared.

Use Node >=22.19 (local tested runtime Node 24.14.1). Copy `public` to `.next-rhine-v8/standalone/public`, and `.next-rhine-v8/static` to `.next-rhine-v8/standalone/.next-rhine-v8/static`. Start `.next-rhine-v8/standalone/server.js` with `.env.local`, HOSTNAME=0.0.0.0 and PORT=3000, or use `pnpm start:rhine`. Binding to `0.0.0.0` allows localhost and LAN/iPad clients to connect. To roll back, stop that process and start the previous `.next-rhine-v7/standalone/server.js` with the same `.env.local`, or an earlier release with its corresponding backup config. Do not clear browser storage.
